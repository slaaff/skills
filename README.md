# Gemini / Antigravity Skills

Coleção de skills para o Google Antigravity / Gemini CLI.

## Como instalar no PC / Linux / Termux

Clone este repositório diretamente na pasta de skills do seu usuário:

### Linux / WSL / Termux:
```bash
git clone https://github.com/slaaff/skills.git ~/.gemini/skills
```

### Windows (PowerShell):
```powershell
git clone https://github.com/slaaff/skills.git $HOME\.gemini\skills
```

## Skills Incluídas:
- **karpathy-guidelines**: Diretrizes comportamentais e prevenção de erros comuns de LLMs em código.
- **graphify**: Conversão de código/docs em grafos de conhecimento e relatórios visuais.
- **ponytail**: Suite de minimalismo e eficiência (ponytail, ponytail-audit, ponytail-debt, ponytail-gain, ponytail-help, ponytail-review).
- **react-best-practices**: Otimizações e boas práticas de React/Next.js pela Vercel.
- **react-view-transitions**: Animações nativas usando View Transition API.
- **composition-patterns**: Padrões avançados de composição de componentes React.
- **react-native-skills**: Boas práticas para React Native e Expo.
- **deploy-to-vercel & vercel-cli-with-tokens**: Utilitários de deploy e gestão de ambientes Vercel.
- **vercel-optimize**: Otimização de custos e desempenho na Vercel.
- **web-design-guidelines & writing-guidelines**: Diretrizes de UI/UX e escrita técnica.
